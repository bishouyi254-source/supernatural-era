## 0.24.7 · 角色五维潜质与死亡轮回正式集成

角色创建新增身高、体重、年龄三个静态特征，以及体质、初始精神基础值两个独立成长潜质。体质决定厉鬼驾驭容量门槛，精神潜质影响额外灵异调用、规则对抗加成与能力开发上限，原有逐鬼负荷/复苏代价不变。死亡结算使用真实行动记录评定 D/C/B/A/S 并发放永久潜质点；死亡正式提交后分配奖励，下一轮角色继承潜质，不自动继承厉鬼、事件和物资。
